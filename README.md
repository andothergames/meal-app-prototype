# Creative Meal Plan App - Prototype

Work made for the Creative Coding Level 6 Final Project at Norwich University of the Arts.

###  🍽️ Running the Project

To run the prototype, download the code and run index.html within the browser.

Select different ingredients and click on the plate to create a meal collage.

Alternatively, [access the prototype online](https://andothergames.github.io/meal-app-prototype/)
