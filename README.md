# Creative Meal Plan App - Prototype

Final project for the Creative Coding Level 6 Course at Norwich University of the Arts.

###  🍽️ Running the Project

To run the prototype, download the code and run index.html within the browser or [access the prototype online](https://andothergames.github.io/meal-app-prototype/)

Select different ingredients from the drop down list and click on the plate to create a meal collage.
